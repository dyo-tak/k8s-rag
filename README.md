# k8s-rag

**Kubernetes support-assistant — RAG over the official docs, with a retrieval eval that gates quality.**

Ask things like "why is my pod CrashLooping" or "how do I set CPU limits" and get answers
grounded in (and citing) the official Kubernetes documentation.

## Architecture

```
manifest/docs_manifest.txt        curated corpus (37 official docs pages)
        │  scripts/fetch_docs.py
        ▼
data/k8s_docs/**/*.md
        │  src/rag/ingest/chunking.py   (markdown-aware: headings → sections → recursive split)
        │  scripts/build_index.py       (Chroma + local MiniLM embeddings, no API key)
        ▼
chroma_db/  ◄──  src/rag/retrieval/retriever.py  (MMR, k=5)
                        │
        src/rag/chain.py (prompt → LLM → cited answer) ── src/rag/api.py (FastAPI)
                        │
        scripts/eval_retrieval.py  →  eval/results.json   (hit@5 — the quality gate)
```

## Quickstart

```bash
uv sync
uv run python scripts/fetch_docs.py
uv run python scripts/build_index.py
uv run pytest                              # chunking tests
uv run python scripts/eval_retrieval.py    # retrieval hit@5 — no API key needed
cp .env.example .env                       # add OPENROUTER_API_KEY for the LLM part
uv run uvicorn src.rag.api:app --port 8000
```
